## RuneLite (BSD 2-Clause)

The build and launcher follow the official
[example plugin](https://github.com/runelite/example-plugin). RuneLite is a build and runtime
dependency and is not bundled in the plugin JAR; game identifiers are referenced from the RuneLite
API's `net.runelite.api.gameval` classes at compile time.

`src/main/resources/com/blackbox/names.tsv.gz` is a table of the names behind game ids (136,217
entries: varbits, varps, interfaces, inventories, animations, spot animations, NPCs, objects and
items), generated from the constant names in the `net.runelite.api.gameval` classes of
`net.runelite:runelite-api` **1.13.2** (checked: its 13,570 varbit names match that version exactly
and no other). It is shipped inside the plugin JAR so an export can name the ids it mentions
(`names.txt`). Those classes are generated by RuneLite from the game's data and are distributed
under RuneLite's license, reproduced in full below. The names are the game's own; the game and its
data are Jagex's.

RuneLite's source was also read, with nothing copied, to learn how the client behaves: where
`PluginManager` looks for sideloaded plugins, and how the client's logging is set up (Black Box
attaches its own appender to the client's logback root logger at run time; logback itself is part
of the client and not bundled).
